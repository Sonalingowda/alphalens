## Targeted changes

Only these package changes were made:

- `next`: `16.2.12` -> `16.4.3`.
- `eslint-config-next`: aligned to `16.4.3`.
- `shadcn`: moved from `dependencies` to `devDependencies`, version `4.22.0`.
- `postcss`: `^8.5.25` -> `^8.5.31`.
- Removed the prior `overrides` block. No forced upgrade, audit suppression, or
  new override was used.
- `package-lock.json` was regenerated by npm from the declared package graph.

Compatibility checks:

- Next `16.4.3` accepts React 19 and Node >=20.9; candidate uses React
  `19.2.4` and Node `22.23.3`.
- `@clerk/nextjs@7.9.7` accepts Next 16.x and remained unchanged.
- Next resolved stable `sharp@0.35.5` without an override.
